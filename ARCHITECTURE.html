1. 项目概述

家庭资产管理系统是一个多人账户的个人财务追踪工具，支持资产录入、分类统计、理财目标管理等功能。

核心特性：

  • 多用户 JWT 鉴权，数据完全隔离
  • 资产按「现金 / 固收 / 权益 / 另类 / 负债」五大类管理
  • 首页 SVG 饼图可视化资产配置
  • 理财目标进度追踪（支持拖拽排序）
  • 三端同构后端逻辑：本地 / Vercel / Cloudflare Pages 均可部署

2. 技术栈

HTML5 Drag and Drop API桌面端目标拖拽排序

5.2 认证流程

sequenceDiagram participant C as 浏览器客户端 participant S as 服务端 C->>S: POST /api/login (username, password) S->>S: bcrypt.compare(password, hash) S->>S: jwt.sign({userId}, SECRET, 7d) S-->>C: {token, username} C->>C: localStorage.setItem(token) Note over C,S: 后续受保护请求 C->>S: GET /api/assets Authorization Bearer token S->>S: jwt.verify(token) 解析 req.userId S->>S: 过滤 user_id === req.userId S-->>C: assets[]

5.3 Cloudflare Functions 说明

Cloudflare 版本不使用 Express，每个文件导出 onRequest(context) 函数，依赖 _utils.js 实现 JWT 校验，直接读写 context.env.FAMILYASSETS_KV。

6. API 接口清单

所有接口均以 /api 为前缀，需要鉴权的接口须携带 Authorization: Bearer <token> 请求头。

认证接口

方法路径鉴权说明
POST/api/register无用户注册（密码 ≥ 6 位）
POST/api/login无用户登录，返回 JWT token

资产接口

方法路径鉴权说明
GET/api/assets需要获取当前用户全部资产（按创建时间倒序）
POST/api/assets需要新增资产
PUT/api/assets/:id需要更新资产
DELETE/api/assets/:id需要删除资产
GET/api/assets/statistics需要按类型汇总统计

目标接口 仅 Cloudflare 版本

方法路径鉴权说明
GET/api/goals需要获取目标列表（按 order 排序）
POST/api/goals需要新增目标
PUT/api/goals/:id需要更新目标
DELETE/api/goals/:id需要删除目标
POST/api/goals/reorder需要拖拽排序（提交新 order 数组）

统计接口

方法路径鉴权说明
GET/api/statistics需要总资产、资产数量、分类统计

7. 数据模型

ER 图

erDiagram User { int id PK string username string password string created_at } Asset { int id PK int user_id FK string name string category string type float amount float principal float expectedReturn string description string created_at string updated_at } Goal { string id PK int user_id FK string name float targetAmount float currentAmount string deadline int order string created_at } User ||--o{ Asset : "拥有" User ||--o{ Goal : "设定"

Asset 字段说明

  • category：五大分类之一（现金 / 固收 / 权益 / 另类 / 负债）
  • type：细分类型（如「货币基金」「股票」「活期存款」）
  • amount：当前市值，负债填负数
  • principal：成本/本金（用于计算收益率）
  • expectedReturn：预期年化收益率（%）
